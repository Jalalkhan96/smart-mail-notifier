Privacy

Everything this extension reads — sender, subject, snippet — comes from Gmail's own inbox feed using the Gmail sessions already signed in inside Chrome, and is stored only in your browser via chrome.storage. No Google API keys, no OAuth, no other servers.

It can only see unread inbox mail and is strictly read-only: it cannot send, archive, or modify anything.
